O que são Strings?
String é uma sequência de caracteres, usada para representar texto em Python.
Pode ser compreendidas entre aspas duplas(") ou aspas simples('), ou aspas triplas (""",""") para texto com múltiplas linhas.
codificação em 16 bits, não entra alguns acentos e ç. Cada letra pode ser representada em número a é 1.

• Dado que string são sequências de caracter
Espaço em branco também retorna e é um espaço. \n é o código do Enter, ele pula o enter. Ele retornando no print ele pula duas linhas, \n é interpretado como um só caractere. \t é um Tab. Se você colocar dois vai retorna um espaço maior.
Se você pedir para retorna ou acessar uma posição do string que não existe ele não dá, Erro.
• Dá para fazer Slice
Ele funciona igual lista. Tem como usar - num e num em um só slice. Tipo, [-17:25].
• O operador + utilizado em strings representa a concatenação(junção)
nome = "Ana"
sobrenome = "Silva
print(nome + " " + sobrenome) # Ana Silva
• Assim como em lista, tem multiplicação
print("Python! " * 3) # Python! Python! Python!
